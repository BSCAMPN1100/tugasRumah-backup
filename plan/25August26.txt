| Field             | Type                | Null | Key | Default | Extra          |

| name              | varchar(255)        | NO   |     | NULL    |                |

| password          | varchar(255)        | NO   |     | NULL    |                |
| remember_token    | varchar(100)        | YES  |     | NULL    |                |

| updated_at        | timestamp           | YES  |     | NULL    |                |
+-------------------+---------------------+------+-----+---------+----------------+
   
   ATAU :
  [
  •Informasi Utama
  Primary Key: id
  Kolom Unik: email (Tidak boleh ada yang kembar)
  •Daftar Kolom dan Tipe Data
  1. id
  Tipe: Angka besar positif (bigint unsigned)
  Sifat: Isi otomatis (auto_increment), wajib diisi.
  2. name
  Tipe: Teks pendek (Maksimal 255 karakter)
  Sifat: Wajib diisi.
  3. email
  Tipe: Teks pendek (Maksimal 255 karakter)
  Sifat: Wajib diisi, harus unik (UNI).
  4. email_verified_at
  Tipe: Tanggal & Waktu (timestamp)
  Sifat: Boleh kosong (NULL), mencatat kapan email diverifikasi.
  5. password
  Tipe: Teks pendek enkripsi (Maksimal 255 karakter)
  Sifat: Wajib diisi.
  6. remember_token
  Tipe: Teks pendek (Maksimal 100 karakter)
  Sifat: Boleh kosong (NULL), digunakan untuk fitur "Remember Me".
  7. created_at
  Tipe: Tanggal & Waktu (timestamp)
  Sifat: Boleh kosong (NULL), mencatat waktu data dibuat.
  8. updated_at
  Tipe: Tanggal & Waktu (timestamp)
  Sifat: Boleh kosong (NULL), mencatat waktu data diubah.
]
