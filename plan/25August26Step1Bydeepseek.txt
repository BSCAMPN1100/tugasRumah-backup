3. Buat LoginController

```bash
php artisan make:controller Auth/LoginController
```

File akan dibuat di app/Http/Controllers/Auth/LoginController.php. Isi dengan:

```php
<?php

namespace App\Http\Controllers\Auth;

use App\Http\Controllers\Controller;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Auth;

class LoginController extends Controller
{
    public function showLoginForm()
    {
        return view('auth.login');
    }

    public function login(Request $request)
    {
        // Validasi input
        $credentials = $request->validate([
            'username' => ['required', 'string'],
            'password' => ['required', 'string'],
        ]);

        // Coba login dengan field 'name' sebagai username
        if (Auth::attempt(['name' => $credentials['username'], 'password' => $credentials['password']])) {
            $request->session()->regenerate();

            // Redirect berdasarkan role
            $user = Auth::user();
            if ($user->role === 'admin') {
                return redirect()->intended('/dashboard/admin');
            } elseif ($user->role === 'sales') {
                return redirect()->intended('/dashboard/sales');
            }

            // fallback (seharusnya tidak terjadi)
            return redirect('/dashboard');
        }

        // Jika gagal, kembali dengan error
        return back()->withErrors([
            'username' => 'Username atau password salah.',
        ])->onlyInput('username');
    }

    public function logout(Request $request)
    {
        Auth::logout();
        $request->session()->invalidate();
        $request->session()->regenerateToken();
        return redirect('/login');
    }
}
```

4. Buat Middleware CheckRole (opsional untuk proteksi dashboard)

```bash
php artisan make:middleware CheckRole
```

File di app/Http/Middleware/CheckRole.php:

```php
<?php

namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Auth;

class CheckRole
{
    public function handle(Request $request, Closure $next, ...$roles)
    {
        if (!Auth::check()) {
            return redirect('/login');
        }

        $user = Auth::user();
        if (in_array($user->role, $roles)) {
            return $next($request);
        }

        abort(403, 'Akses ditolak.');
    }
}
```

Daftarkan middleware di app/Http/Kernel.php pada array $routeMiddleware:

```php
'role' => \App\Http\Middleware\CheckRole::class,
```

6. Routes

Ubah file routes/web.php menjadi:

```php
<?php

use App\Http\Controllers\MasterController;
use App\Http\Controllers\Auth\LoginController;
use Illuminate\Support\Facades\Route;

// Halaman login
Route::get('/login', [LoginController::class, 'showLoginForm'])->name('login');
Route::post('/login', [LoginController::class, 'login']);
Route::post('/logout', [LoginController::class, 'logout'])->name('logout');

// Dashboard (dengan middleware auth dan role)
Route::middleware(['auth', 'role:admin'])->group(function () {
    Route::get('/dashboard/admin', function () {
        return view('dashboard.admin'); // nanti kita buat
    });
});

Route::middleware(['auth', 'role:sales'])->group(function () {
    Route::get('/dashboard/sales', function () {
        return view('dashboard.sales'); // nanti kita buat
    });
});

// Route lama (master) - bisa tetap diakses semua, atau kita proteksi juga
Route::get('/master', [MasterController::class, 'index'])->middleware(['auth', 'role:admin']);
```

Catatan: Untuk sementara, kita belum membuat view dashboard admin/sales. Nanti setelah login berhasil, kita akan buat halaman dashboard sederhana.

Pendaftaran Middleware di Laravel 11+

Buka file bootstrap/app.php (bukan app/Http/Kernel.php). Di dalam file tersebut, cari bagian ->withMiddleware() dan tambahkan alias middleware seperti ini:

```php
->withMiddleware(function (Middleware $middleware) {
    $middleware->alias([
        'role' => \App\Http\Middleware\CheckRole::class,
    ]);
})
```

Contoh penuh file bootstrap/app.php (bagian yang relevan):

```php
<?php

use Illuminate\Foundation\Application;
use Illuminate\Foundation\Configuration\Exceptions;
use Illuminate\Foundation\Configuration\Middleware;

return Application::configure(basePath: dirname(__DIR__))
    ->withRouting(
        web: __DIR__.'/../routes/web.php',
        // ...
    )
    ->withMiddleware(function (Middleware $middleware) {
        $middleware->alias([
            'role' => \App\Http\Middleware\CheckRole::class,
        ]);
    })
    ->withExceptions(function (Exceptions $exceptions) {
        //
    })->create();
```

Setelah menambahkan, simpan file.

4. Update file routes/web.php

Ganti isi routes/web.php dengan yang berikut (pertahankan route /master yang sudah ada, tambahkan login, logout, dashboard):

```php
<?php

use App\Http\Controllers\MasterController;
use App\Http\Controllers\Auth\LoginController;
use Illuminate\Support\Facades\Route;

// Halaman login
Route::get('/login', [LoginController::class, 'showLoginForm'])->name('login');
Route::post('/login', [LoginController::class, 'login']);
Route::post('/logout', [LoginController::class, 'logout'])->name('logout');

// Dashboard (dengan middleware auth dan role)
Route::middleware(['auth', 'role:admin'])->group(function () {
    Route::get('/dashboard/admin', function () {
        return view('dashboard.admin');
    });
});

Route::middleware(['auth', 'role:sales'])->group(function () {
    Route::get('/dashboard/sales', function () {
        return view('dashboard.sales');
    });
});

// Route lama (master) - tetap bisa diakses, tapi kita proteksi hanya untuk admin
Route::get('/master', [MasterController::class, 'index'])->middleware(['auth', 'role:admin']);
```
